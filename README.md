# Seven Art Studios — Portfólio

Site estático preparado para publicação no GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, a pasta `assets/` e este `README.md` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/(root)`, e salve.
5. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

Mantenha a pasta `assets/` junto do `index.html`; ela contém as imagens utilizadas pelo site.
